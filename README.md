# Python Learning Curriculum

A comprehensive, week-by-week Python learning program covering fundamental to advanced concepts in programming, data science, and software best practices.

## 📋 Overview

This curriculum is structured into 7 weeks of progressive learning, with each week containing lessons, exercises, and code challenges. All materials are provided as Jupyter notebooks and Python scripts for interactive learning and practice.

---

## 📚 Curriculum Structure

### **Week 1: Python Fundamentals**

Introduction to core Python concepts and data structures.

#### Python Variables and Data Types
- `Casting_variables_to_different_data_types_example.ipynb` - Learn type casting and conversion techniques
- `Data_types_and_operators_exercise.ipynb` - Practice working with different data types and operators
- `Introduction_to_strings_example.ipynb` - String basics and manipulation
- `String_manipulation_techniques_example.ipynb` - Advanced string operations

#### Python Data Structures
- `Lists_examples.ipynb` & `Lists_exercise.ipynb` - Working with lists and common operations

## 🎯 How to Use This Curriculum

1. **Follow the weekly structure** - Proceed through weeks 1-7 in order
2. **Study examples first** - Review `*_examples.ipynb` files to learn concepts
3. **Complete exercises** - Work through `*_exercise.ipynb` files to practice
4. **Challenge yourself** - Complete code challenges for practical application
5. **Use Python scripts** - Reference `.py` files for additional implementations and algorithms
6. **Revisit concepts** - Use notebooks as reference materials when needed

## 💻 Requirements

- Python 3.7+
- Jupyter Notebook or Jupyter Lab
- Required libraries: pandas, matplotlib, numpy (introduced in later weeks)

## 📝 Notes

- Each notebook is designed to be self-contained
- Exercises build on knowledge from examples
- Code challenges synthesize multiple concepts
- Practice regularly for best results
